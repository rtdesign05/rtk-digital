## Technique
Site statique en un seul fichier (`index.html`), sans framework ni dépendance : CSS et JavaScript intégrés, animations en CSS, images en WebP, une seule requête de polices (Google Fonts). Compatible thème clair et sombre, accessible au clavier, respecte « réduire les animations ».

## Structure
```
index.html   la page
assets/      photos, CV (PDF) et captures de projets
```

## Ajouter des captures
Déposer des fichiers `.webp` dans `assets/` avec ces noms (1 à 3 par projet), ils s'affichent automatiquement :
`athenis-1.webp`, `continent-1.webp`, `rivegauche-1.webp`, `emeraude-1.webp`, `tycoon-1.webp`, `mariage-1.webp` (puis `-2`, `-3`).

## Déploiement
Hébergement gratuit sur Vercel : importer le dépôt, framework « Other », puis ajouter le domaine dans Settings > Domains.
